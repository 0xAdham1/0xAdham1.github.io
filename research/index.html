Krayin CRM

A white-box security review of Krayin CRM (krayin/laravel-crm) turned up three vulnerabilities, all responsibly disclosed and patched in release 2.2.7:

IDOR (CWE-639) BOLA (CWE-639) SSRF / DNS Rebinding (CWE-918 / CWE-367)
  • CVE-2026-112286 (Severity: High 7.1) — Quote module IDOR, cross-user read (CWE-639)
  • CVE-2026-112287 (Severity: High 8.3) — Mail module BOLA on the write path (CWE-639)
  • CVE-2026-112288 (Severity: Low 3.1) — Webhook SSRF filter bypass via DNS rebinding (CWE-918 / CWE-367)
